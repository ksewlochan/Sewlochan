## Markdown
- [https://www.markdownguide.org/](https://www.markdownguide.org/)
- Basic viewer (can view but not edit) so a great quick view
	- Windows: [https://apps.microsoft.com/detail/9n6pkz6fp1ml?hl=en-GB&gl=CA](https://apps.microsoft.com/detail/9n6pkz6fp1ml?hl=en-GB&gl=CA)
	- MAC: Don't know but here is one available in the app store on a Mac.
		- https://macmdviewer.com/blog/markdown-viewer-macos
- If you want to edit then you need to look at [Obsidian](#obsidian).

## Obsidian
- [https://obsidian.md/](https://obsidian.md/)
- [https://www.youtube.com/watch?v=z4AbijUCoKU](https://www.youtube.com/watch?v=z4AbijUCoKU)
	- Overview
	- Install the **AnuPpuccin** theme (don't need Soft Paper)
	- Enable: Settings > Files and Links > Automatically update internal links
	- A good recommended video before you start using Obsidian
- [https://www.youtube.com/shorts/xHGphyA2mZw](https://www.youtube.com/shorts/xHGphyA2mZw)
	- Initial settings to set (same as above but quicker).
- [https://www.youtube.com/watch?v=Tmatz3wPEJo](https://www.youtube.com/watch?v=Tmatz3wPEJo)
	- Bases - intro
